    What Delta is

    Delta Agent is a coding agent that runs in your terminal. You talk in natural language and it does the work: reads files, writes code, runs commands, handles git, searches the web and explains what it found.

    It is a single executable written in C11 with no runtime: no Node, Python, npm, and no administrator rights. It talks to the model provider you choose and keeps everything that is yours in one folder.

    What it does

    filesread, create, edit precisely and search the project shellrun commands, background jobs and see the output gitstatus, diff, log, commit and checkpoint before changing anything webdownload pages, extract data and read documentation skillssaved workflows in SKILL.md that it reuses mcptalk to MCP servers over HTTP or stdio (JSON-RPC) memorykeep durable facts across sessions modelshundreds of models and providers from models.dev

    How it works

    Every request becomes a turn: the model streams a reply, asks for tools, Delta runs them and returns the result, until the task is done. You can type while it works — the message joins the conversation mid-turn and it changes direction immediately.

    The model is not fixed: /models lists what your providers offer and /thinking adjusts the reasoning effort.

    Where your data lives

    All in one folder (the one you chose at install time, by default C:\Users\you\.deltaCore):

    config.jsonprovider, model, language, project folder auth.jsonone API key per provider sessions/history per folder, in JSONL skills/your skills (<name>/SKILL.md) mcps/one .json per MCP server extensions/pluggable extensions system/prompt.mdrules it must always follow

    Requirements

    • Windows 10/11 x64 (the binary is self-contained)
    • internet to reach the model provider
    • an API key from the provider you use
    documentation

    How to use

    First run

    Open a new terminal and type delta. On the first run, connect a provider:

    /login # lists providers, asks for the key, picks a model
    /projects D:\dev\my-app # start working there (saved)
    # now just describe what you want
    read src/main.c and explain the flow

    Resume your work

    delta always starts a new chat in that folder. To continue where you stopped — messages, tool calls and the model's thinking included — run delta continue. Inside the session, /new starts fresh.

    Commands

    /loginpick a provider and paste the key /modelsmodels from connected providers /thinkingreasoning effort /projectsfolder where it works /terminalrun a shell command and show the output /undorestore the previous content of a file /subagentmodelmodel the subagents run on (it asks before creating one) /deltagroupDelta group on Telegram (invite link) /updateinstall the newest release from GitHub /statusconfiguration and usage /helpall commands and shortcuts

    Shortcuts

    Entersend (while working: it joins the queue and it reads it mid-turn) Shift+Enternew line Ctrl+Cwith a selection: copies it; otherwise stops the generation (never closes the app) Ctrl+Vpaste text, image or file Ctrl+Qreturn the last queued message to the editor mousewheel scrolls; drag selects (white on black), click clears Escgo back to the end of the conversation

    Your system

    Write in system/prompt.md (inside the data folder) what Delta must always follow: tone, format, team rules. It re-reads the file on every turn.

    Common issues

    • “no API key” — run /login or set OPENAI_API_KEY / ANTHROPIC_API_KEY.
    • “catalog unavailable” — no network on the first run; try again.
    • delta is not recognized — open a new terminal (the PATH was updated) or use the full path shown by the installer.
    • SmartScreen on first run — “More info → Run anyway”.
