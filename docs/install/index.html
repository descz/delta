install

Install Delta Agent

One file per platform. The download is the installer: it asks for the data folder, copies the binary, puts delta on your PATH and creates the shortcut. No admin, no Node, no Python, no package manager.

Windows 10/11 x64

Delta.exe — 809 KB, program and installer in one file. The reference platform: 353 automated checks.

Linux x86_64

delta-linux-x86_64.run — self-extracting. Needs curl at runtime to reach the provider.

macOS 11+ source

Source package with INSTALAR-MAC.command: builds on your machine with the Xcode Command Line Tools.

Windows 10/11 x64

Download Delta.exe (or Delta-windows-x64.zip) from Releases and double click.

  1. Double click Delta.exe. A small install window opens — an HTML popup served by the executable itself, with no browser tab left behind.
  2. Pick where the data lives (default C:\Users\<you>\.deltaCore).
  3. The installer copies the binary, adds delta to your user PATH and creates the shortcut. No administrator rights.
  4. Open a new terminal and run delta.
# SmartScreen on the first run
"Windows protected your PC" -> More info -> Run anyway
# the binary is not code-signed; that is the whole story, nothing else

The installer reopens at any time with delta --setup. To uninstall: delete the data folder and remove delta from PATH — there is no registry entry and no service.

Linux x86_64

Two shapes: the self-extracting installer or the plain tarball.

# self-extracting installer (installs and puts delta on PATH)
chmod +x delta-linux-x86_64.run && ./delta-linux-x86_64.run

# or the tarball
tar xzf delta-linux-x86_64.tar.gz && cd delta-linux-x86_64 && ./install.sh

# check
delta --version

Verified on WSL with gcc 13: build, CLI, TUI, real streaming and self-update. The desktop layer — .desktop entry, GNOME favorites and the clipboard through wl-copy/xclip — was not exercised on a desktop session, so treat that part as untested. curl must be installed.

macOS 11+ source

There is no prebuilt Mach-O: the package ships the source and a script that builds it locally.

xcode-select --install          # free, once
unzip delta-macos-source.zip
cd delta-macos-source && ./INSTALAR-MAC.command

The script checks the Xcode Command Line Tools, builds and opens the installer. The native parts (osascript, .app, Dock) were written but never executed by the author — no Mac available. This is the least supported of the three paths.

First run

delta                    # opens the CLI (always a new chat)
/login                   # pick the provider, paste the key
/projects ~/dev/my-app   # where it works (saved for next time)
read src/main.c and explain the flow

delta continue           # reopens this folder's last chat, thinking included
delta update --check     # only reports; `delta update` installs

Keys are stored per provider in auth.json inside the data folder. Nothing leaves the machine except the requests to the provider you configured.

Where your data lives

One folder, chosen at install time (default ~/.deltaCore). Every file is written to a temporary and swapped in one step, so a second window never reads half a config.

.deltaCore/
  config.json        provider, model, language, thinking, projectDir
  auth.json          one API key per provider
  sessions/          --<folder-slug>--/<date>_<id>.jsonl
  skills/            <name>/SKILL.md
  mcps/ extensions/  servers and pluggable extensions (tool, skill, command, mcp, hook)
  memory.json        durable facts, searchable
  graphs/            project graph cache (symbols and imports)
  system/prompt.md   team rules, re-read every turn

Backup is copying the folder. Migration is the same: point the installer at the new path.
