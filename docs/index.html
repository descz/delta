01 — o produto

Um binário, um agente

O Delta é um agente de codificação de terminal. Ele segura o loop: fala com o modelo, recebe pedidos de ferramenta, executa e devolve o resultado — até a tarefa terminar. Você não monta prompt de sistema, não cola arquivo: descreve o que quer e revisa o que ele fez.

Leitura e escrita

lê arquivos (com limites e offset), cria, edita por trechos exatos, busca no projeto, lista estrutura, mostra diff e faz checkpoint no git antes de mexer.

Shell de verdade

roda comandos com timeout, mantém jobs em background com log, e o /terminal <cmd> executa no seu shell e mostra a saída num bloco no chat.

Git sem susto

status, diff, log, commit e checkpoint — ele salva o estado antes de alterar, então dá para voltar sem perder trabalho.

Web e MCP

baixa páginas, extrai links/dados, segue redirects, e fala JSON-RPC com servidores MCP registrados em ~/.deltaCore/mcps/.

Skills e memória

fluxos repetidos viram SKILL.md e entram no índice do prompt; fatos duráveis ficam na memória e são buscados antes de perguntar de novo.

Modelos à escolha

catálogo models.dev: centenas de modelos e provedores. /models lista os conectados, /thinking ajusta o esforço de raciocínio.

TUI própria

tela alternativa, markdown renderizado (títulos, listas, tabelas, código), temas, 5 idiomas, mouse e seleção com cópia.

Sessões por pasta

histórico em JSONL por diretório: delta reabre o último chat daquela pasta.

Streaming com steer

digite enquanto ele trabalha: a mensagem entra na fila e ele corta a resposta no meio para lê-la.

Instalador embutido

o próprio executável sobe uma página local, escolhe a pasta e se instala no PATH com atalho.

02 — como funciona

Um turno, cinco passos

O agente é dono do loop; o modelo só pede. Cada pedido de ferramenta vira uma execução real no seu projeto, e o resultado volta para o modelo decidir o próximo passo.

01você escreve
02modelo responde em streaming
03pede ferramentas (JSON)
04Delta executa e devolve
05repete até terminar

Quando você digita no meio do turno, o stream é cortado no próximo fragmento, o texto parcial fica no histórico e a sua mensagem entra como novo passo — sem esperar a resposta final.

Render incremental

cada bloco guarda a linha onde começa; o transcript é remontado a partir do primeiro bloco sujo. Frame típico: 0,5 ms com centenas de blocos.

Terminal nativo

modo cru com ReadConsoleInput no Windows e termios no POSIX; mouse, colagem, redimensionamento e tela alternativa.

Rede enxuta

WinHTTP no Windows, curl no POSIX. SSE lido linha a linha, com abort imediato quando você interfere.

04 — dados

Uma pasta sua, nada espalhado

Tudo fica na pasta escolhida na instalação (padrão C:\Users\você\.deltaCore).

.deltaCore/
  config.json        provedor, modelo, idioma, thinking, projectDir
  auth.json          uma chave de API por provedor
  models.v2.json     catálogo models.dev em cache
  memory.json        memória durável
  sessions/          --<slug-da-pasta>--/<data>_<id>.jsonl
  skills/            <nome>/SKILL.md
  mcps/              um .json por servidor MCP
  extensions/        extensões plugáveis
  system/prompt.md   o que ele deve obedecer sempre
  paste/ jobs/ themes/

system/prompt.md é relido a cada turno: é ali que você escreve as regras do time.

06 — faq

Perguntas curtas

Preciso de chave de API?

Sim, de um provedor que você use (OpenAI, Anthropic, OpenRouter, DeepSeek, opencode…). /login pede a chave uma vez e guarda em auth.json por provedor.

Roda offline?

O programa roda; o modelo não. Sem rede ele continua abrindo o CLI, as sessões e as ferramentas locais — mas não conversa com o provedor.

Por que C11?

Um executável, sem runtime, abre instantaneamente e não quebra com atualização de Node. A TUI, o parser JSON, o markdown e o cliente HTTP são todos nossos.

O Windows avisou que o app é desconhecido

É o SmartScreen por falta de assinatura digital: Mais informações → Executar assim mesmo.

E no macOS?

O binário precisa ser compilado na máquina (não há cross-compile confiável para Mach-O). O pacote traz um .command que confere as Xcode Command Line Tools e faz tudo.

Meus dados vão para algum lugar?

Só para o provedor que você configurar. Histórico, chaves, memória e skills ficam na sua pasta .deltaCore.
